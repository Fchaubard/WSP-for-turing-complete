Return one JSON object with exactly these fields: family (your description), inferred_rule (brief), construction_summary (up to 150 words), certificate (a short checkable mathematical justification, not a private reasoning trace), and network.
network is either:
{"kind":"graph","nodes":[...],"output":"node_name"}
or
{"kind":"recurrent","initial_state":[numeric values],"cell":[...],"state_output":"node_name","readout":[...],"output":"node_name"}.
You choose all widths, depths, connections and coefficients. Name every node uniquely within its graph. A node has {"name":"...","op":"...",...}.
Allowed forms are:
- {"name":...,"op":"constant","value":[numbers]} (a scalar is [number]; matrices may be nested)
- {"name":...,"op":"affine","source":"tensor","weight":[[numbers],...],"bias":[numbers]} computes W @ source.reshape(-1) + bias. Bias may be omitted.
- {"name":...,"op":"relu"|"tanh"|"sigmoid","source":"tensor"} applies elementwise.
- {"name":...,"op":"add"|"multiply"|"matmul","left":"tensor","right":"tensor"} uses NumPy broadcasting or matrix multiplication.
- {"name":...,"op":"concat","sources":["tensor",...]} concatenates flattened tensors.
- {"name":...,"op":"take","source":"tensor","indices":[integer,...]} indexes the flattened source, including repeated indices.
- {"name":...,"op":"reshape","source":"tensor","shape":[positive integers]} changes shape without arithmetic; total size must match.
- {"name":...,"op":"transpose","source":"tensor"} transposes a matrix.
- {"name":...,"op":"softmax","source":"tensor"} normalizes along the final axis using max subtraction.
- {"name":...,"op":"conv1d","source":"tensor","weight":[[[numbers],...],...],"bias":[numbers]} uses valid stride-one convolution. Source shape (length,input_channels), weight shape (output_channels,input_channels,kernel_width); output shape (length-kernel_width+1,output_channels). Bias optional.
Node references must be to external tensors or earlier nodes. Graph input is named "input". Recurrent cell external names are "state" and "input". Readout external names are "state" and "input"; it may directly return state without nodes. For integer index n, initialize the state, repeat the cell n times with input [0], then read out; n=0 reads the initial state. For streams, feed [x_t], update the state and read out after every element. Shared cell and readout weights are stored once. Return actual finite JSON numbers, never formulas or code strings in coefficient fields. The final output may be the external input or state. There may be at most 64 total nodes, at most 4096 stored scalar coefficients including constants and initial state, and at most 65536 simultaneously live activation scalars. Scalar outputs have one entry. All inference is binary64. No sin, exp, log, pow, sort, Fibonacci or triangular target-specific operation is allowed; tanh, sigmoid and softmax perform their named standard neural activations. Elementwise multiplication is an allowed neural gating primitive. Every stored coefficient, including zero/one, counts toward storage. Graph topology also consumes serialized storage. Do not artificially inflate an error to reduce resource cost.
