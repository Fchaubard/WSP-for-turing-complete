# Architecture discovery from examples, protocol 1

Fixed before model requests and held-out scoring. Use ten original task families and the three recorded data seeds 164, 317 and 583. Each of the 30 independent requests receives exactly its original 12 labeled input/output examples, or nine integer indices, the input/output shape and the deployment domain. The request contains no task name, target formula, initialized weights, prescribed width, layer count or architecture family. It states extrapolation as the primary goal, then asks for a compact implementation minimizing coefficients, batch-one inference workspace and scalar arithmetic. All responses are first replies, without validation feedback or solver tools. Record one proposal per request, including failures. No candidate selection by training or test scores occurs.

The allowed neural graph language permits arbitrary compositions of affine maps, ReLU, tanh, sigmoid, elementwise addition and multiplication, concatenation, static indexing, reshaping, transposition, matrix multiplication, softmax, one-dimensional convolution, and optional recurrence. This permits MLPs, multiplicatively gated networks, recurrent networks, convolutional networks and attention networks. Arbitrary code and target-specific sin, power, sorting or sequence-generator operators are unavailable. A tanh activation and an elementwise product can directly implement some targets, and are counted and disclosed. The maximum proposal has 64 operator nodes across all graphs and 4096 stored floating-point coefficients, including constants and initial state. These are safety/execution bounds, not prescribed candidate sizes. Each graph produces at most 65,536 live scalar activations. A recurrent candidate repeats a shared cell once per supplied stream element or integer index.

A graph source name references a previously computed tensor; the external input is a binary64 tensor named `input`. Sources become available to downstream nodes only. Recurrent cells have `state` and `input`; the readout has the final state and the last input. For an index input, initialize state, run n cell updates with input [0], then run the readout. For sequence input, update the state for each scalar and emit the readout after each update. No updates at index zero. Feedforward index input receives [n] and feedforward sequence input receives the complete stream vector. All mathematical values use NumPy binary64. Scalars are represented as length-one vectors, and broadcasting follows NumPy. Output is reshaped to the target's one-example shape only when the number of entries matches.

Weights and graph are frozen as literal first replies before opening any evaluation inputs. Evaluate original training pairs, untouched original central arrays (integer indices 17–32), original outer arrays (integer indices 33–64), and 2,048 independently drawn post-freeze central/outer examples per stochastic task. Integer index evaluation restarts the network from initial state for each n. Running-sum evaluation also reports length-32 central streams separately. Report exact whole-example count, raw RMSE and scaled RMSE; score errors as failed outcomes without dropping them. A proposal is executable only if it parses as the declared schema, stays within resource limits and emits finite outputs of the specified shape on each evaluated split.

Costs are measured by the interpreter for a batch of one example. Floating-point operations (FLOPs) count scalar adds, subtracts, multiplies, divides and accumulated dot-product additions separately, including multiplies by zero and one. ReLU comparisons and exp/tanh calls are reported separately. Sigmoid has one exponential and three scalar arithmetic operations per element. Softmax uses subtraction of the row maximum, exponentials, sum and division, with comparisons and exponentials separate. Memory reports coefficient bytes (8 per stored scalar) and the peak live input/intermediate/state/output bytes under dependency-based last-use freeing. Affine/conv bias additions count only if a bias was supplied. BLAS and interpreter temporaries, Python objects, allocator overhead and hardware fusion are outside this abstract execution-cost model. Report minimum/maximum/median operation and workspace counts over each evaluated split when input lengths or index values differ. Serialized executable JSON bytes are also reported because topology has a storage cost even for parameter-free graphs. No claim of global cost optimality follows from 30 proposals.

The response includes an inferred-rule statement, architecture family label, short construction summary and checkable certificate fields. These are final-answer explanations requested for publication, not internal reasoning traces. Only actually returned text will be reproduced. The exact prompts, final replies, runtime event metadata and request failures are archived. Use existing gpt-6-astra hosted model alias, medium effort, 300-second call timeout, no automatic retry, and 10 concurrent independent requests. If one attempt fails, record the failure.
