# Architecture discovery from examples

The frozen study sends 30 separate requests to Astra. Each request gives the original observed pairs, shape and deployment domain. It leaves the network family, topology and coefficients to the model. Its primary objective is extrapolation; storage, inference workspace and scalar arithmetic are secondary. The task name and formula are never supplied. The protocol and prompt hashes precede collection, and FROZEN.json precedes held-out scoring. Requests use medium effort and no tools. Public implementation summaries and model-supplied certificate fields are archived with the final replies; these are not internal reasoning traces.

Run with the project's Python/NumPy environment:

- `python focus/architecture_search/evaluate.py` replays all saved model arrays and costs. The recorded post-freeze confirmation seed is reused.
- `python focus/architecture_search/report.py` generates the paper fragments and summaries.
- `collect.py prepare` and `collect.py collect` are the provenance of the existing collection. The released prompts and replies are the observation, so a new hosted-model response is a different experiment.

`models.csv` retains every one of 30 trials, including both invalid self-power graphs. `scores.csv` gives all training, untouched central/early, original outer, independent confirmation, and running-sum length-32 results. `costs.csv` gives measured operation counts and logical live storage for each executable trial/split. `summary.csv` gives ten per-task rows and marks the valid-count denominator; numeric medians there use executable proposals only. Invalid trials retain infinite RMSE in per-trial scores. Resource ranges describe candidates, not a proof of global optimality.

Twenty-eight replies produce executable graphs, and 21 match every original outer output. The three sine networks all give outer RMSE 7.790120819679062e-16; sorting is near floating-point accuracy but whole-list exact rates are about 54%. One self-power graph gives outer RMSE 16759.378581076264. The other two are invalid because one references an undefined `minus_one` and one contains 65 nodes, exceeding the frozen 64-node budget.

Multiplication and tanh are allowed neural primitives. Their availability permits coefficient-free square and tanh graphs. These operators expand the architecture search space beyond the fixed ReLU networks. All three square replies contain one multiplication and zero scalar coefficients, but 109 bytes of executable JSON topology. Zero is the trivial lower bound on stored coefficient count, while the other measured minima have no global certificate. A cost statement always names this operator library and binary64 precision.

The logical workspace measurement materializes graph outputs and frees inputs after their final dependency. It includes input, state and output buffers, and excludes interpreter objects, allocator overhead and hidden BLAS workspaces. Floating-point additions, multiplications and divisions each cost one. Comparisons and transcendental calls are tabulated separately. Index-driven recurrence restarts from initial state for each query. The `*_max` fields therefore use index64 for Fibonacci, and stream length6 for the primary running-sum comparison. Full serialized network bytes are additionally reported to expose topology storage even when no floating coefficients are needed.

Publication inputs are architecture_main_results.tex, architecture_main_table.tex, architecture_appendix.tex and four architecture_*_164_{prompt,reply}.txt files. The appendix requires the standard LaTeX listings package and applies literal Unicode math mappings for the actual model output. Full public explanation fields are reproduced for all30 candidates, including the two invalid graphs. The archived candidate certificates are model claims unless independently proved. The paper-level independently measured errors and costs take precedence over self-reported operation counts in those explanations.

An independent interpreter review is supplied by the separate audit at ../prompt_audit/architecture_review.md and .json. It replayed all28 valid candidates on1,278 scalar output values and independently matched coefficient counts, arithmetic counts, comparisons, transcendental evaluations and the stated logical liveness convention. Synthetic convolution and attention fixtures verify the operators even though none of these30 proposals selected them.
