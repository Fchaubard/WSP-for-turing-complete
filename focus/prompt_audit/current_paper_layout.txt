         Weight-Space Programming and Gradient
        Optimization on Nonconvex Algorithmic Tasks


                                          Francois Chaubard
                                       fchaubar@stanford.edu


                                                Abstract

            The universal approximation theorem guarantees arbitrarily accurate approxima-
            tion of continuous functions on compact domains with suitable activations and
            sufficient width. How should an optimizer find the weights, and which architec-
            ture should it use? We compare weight-space programming (WSP) with gradient
            optimization on ten algorithmic tasks. The fixed-network study covers 29 non-
            convex task–architecture pairs and three random starts, using 3–50 coefficients
            in rectified linear, residual and recurrent networks. Astra, a pretrained language
            model, returns numerical weights in one reply or revises them using training and
            development feedback. Both examples-only WSP procedures match every ex-
            trapolation reference in the same 30 of 87 settings, including addition and running
            sums. Full-batch gradient descent using backpropagation achieves this in zero set-
            tings, as does descent followed by limited-memory Broyden–Fletcher–Goldfarb–
            Shanno (L-BFGS) refinement. Summing each task’s mean raw extrapolation root
            mean squared error (RMSE) ranks the two iterative WSP conditions first among 14
            evaluated pipelines. The examples-only sum falls from 1.06 × 1012 to 2.03 × 109 ,
            driven mainly by improved Fibonacci predictions. The median scaled extrapo-
            lation error instead increases, and stored square-network coefficients show how
            central validation can favor a worse outer continuation. Thirty further requests let
            Astra choose the graph and coefficients from input/output examples, with extrap-
            olation as the primary objective. Twenty-one proposals are exact on every outer
            input. Square uses a single product node with zero stored coefficients, while sine
            attains RMSE 7.79 × 10−16 . Two self-power proposals are invalid. We report
            coefficient storage, live tensor memory and arithmetic costs under the declared
            operation library, and reproduce prompts, returned graphs and public construction
            explanations.


1    Introduction
Universal approximation leaves open how to find the weights of a particular small network. Consider
a network given twelve examples of addition. How closely do the returned weights fit those sums,
and do the same weights still add correctly when both numbers are larger? We evaluate each solver
on both questions. The unit of comparison is a task and architecture: fixing addition as the target
still leaves a choice between a linear map with two coefficients and a network with a trainable hidden
layer. The former has a convex least-squares training loss. The latter can have several weight vectors
that fit equally well and a much worse fit halfway between them.
Weight-space programming (WSP) uses a specification or examples to assign numerical values di-
rectly to a network’s weights. Our solver, GPT-6 Astra (Astra), receives the architecture, a random
initial weight vector and labeled training examples. In one-shot WSP, it returns numerical weights
for every trainable coefficient in a single reply. In iterative WSP, we start with those very weights,
evaluate them on training and development examples, and invite up to three revisions. We keep a re-

vision only if it improves the development loss, using the training loss to break a tie. Each procedure
is run with examples only and with the generating formula supplied alongside the same examples.
Backpropagation (BP) computes a derivative; its use does not specify how to update the weights.
Our first numerical baseline uses that derivative for full-batch gradient descent. Our second begins
at the same gradient-descent endpoint and uses a limited-memory approximation to local curvature
to refine it. We report both checkpoints. Additional comparisons use adaptive gradient steps and
trust-region least squares. We evaluate the weights on the original training data and on disjoint tests
inside and outside the original input range. For integer sequences both tests concern unseen later
indices.
The benchmark covers four elementary functions, two arithmetic operations and four sequence or
sorting tasks. For every included fixed-network task, architecture and training set we exhibit two
weight vectors whose midpoint has higher loss than the average endpoint loss. This strict violation of
the convexity inequality certifies that the empirical objective is nonconvex in its trainable parameters.
It permits the comparison to include linear recurrent networks whose repeated trainable matrices
make their losses nonconvex. We measure how often each method fits the observations more closely,
how often that advantage carries beyond the observed range, and how the outcome changes with the
number of parameters. The question concerns the quality of the returned weights at stated budgets.
The tasks have known mathematical answers and allow direct checks of exactness.
We also ask Astra to choose the architecture from examples. Thirty further requests specify the
observations, deployment domain and supported neural operations. Astra chooses the graph, its
size and coefficients, with extrapolation accuracy as the primary objective and inference cost as
the secondary objective. We evaluate every returned proposal and report its coefficient storage,
activation memory and arithmetic cost.


2   Related Work

Comparing optimizers. DeepOBS pairs tasks with specified networks and evaluates optimization
methods on those problems [18]. Schmidt et al. show experimentally how optimizer performance
varies with task and tuning budget [17]. We use small networks and few observations so that a
language model can receive the entire parameter array, numerical solvers can use individual output
derivatives, and some training optima can be computed independently. Our data also permit separate
measurements of interpolation and extrapolation. We compare final predictions rather than speed at
equal computation.

Constructing weights. Algorithms have long been translated into neural weights, including re-
current computations [19, 25] and sorting in transformers [12]. Recent demonstrations used Astra to
write game-policy weights and modify a pretrained language model [21]. Other WSP studies tested
bounded arithmetic and sorting through repeated proposals [20] or compiled numerical formulas into
neural networks [24]. Our primary comparison fixes every graph, initial array, set of training labels
and scoring objective before collecting its WSP responses. We report both the objective attained on
those labels and accuracy on undisclosed test inputs.

Capacity and extrapolation. Studies of arithmetic networks and algorithmic reasoning show how
computation outside the training range depends on network structure [23, 14, 27, 26]. Universal
approximation gives existence of a network that approximates a continuous function on a compact
domain to a specified positive tolerance [3, 11]. It leaves open the weights an optimizer will find and
the size required to round an answer exactly. Vapnik–Chervonenkis dimension concerns the ability
to realize every binary labeling of a point set [1]. We instead use lower bounds for the particular
task and graph, including a bound on the number of linear pieces of a shallow square network.
Floating-point arithmetic introduces additional expressivity and rounding questions [16, 9, 15, 8].

Selecting the architecture. Neural architecture search selects network structures using measured
performance, as in the recurrent controller of Zoph and Le [29]. Our additional experiment asks
Astra to infer a rule from examples and return both a graph and its numerical coefficients in one
response. We measure extrapolation and execution cost for each returned graph.

3    Tasks, Architectures, and Optimization Methods
An architecture specifies the operations and which scalar coefficients may change. A rectified linear
unit (ReLU) applies R(u) = max(0, u) to an input u. A multilayer perceptron (MLP) applies a
sequence of affine maps (weighted sums plus biases) and activations. A recurrent neural network
(RNN) carries a state vector from one step to the next and reuses the same weights at each step.
Table 1 lists every primary graph. The counts include all trainable biases and shared weights, with
each stored scalar counted once.

perbolic tangent tanh x. For each hidden unit j let uj , vj , cj denote its input slope, offset and output
weight, and let wP be the width. With a direct linear path of slope a and offset b, the scalar predic-

How we checked nonconvexity. For each of the 87 fixed-network settings, we exhibit two weight
vectors whose midpoint has loss strictly greater than the average endpoint loss. Each witness uses
two trainable coefficients that multiply along an active path. Swapping those coefficients preserves
the endpoint prediction while changing the midpoint prediction. Exact rational evaluation on the
actual training observations certifies the violation. Appendix A.8 supplies the construction and its
scope. The additional architecture-selection experiment can choose a different graph and is reported
separately.

Objective and methods. For observed scalar prediction ŷ with label y, the scaled residual is (ŷ −
y)/ max(1, |y|). The common training objective is half the mean squared scaled residual, over every
output coordinate. Both WSP prompts explicitly prioritize this objective and request extrapolation
among similarly good fits. An endpoint is the weight array a method returns using only the specified
training information. The original four endpoints are the two WSP conditions and two numerical
solvers.

       • One-shot WSP. In the Examples only condition, Astra sees the graph, initial weights, in-
         tended input range and examples. In Formula and examples, it also sees the target rule. It
         returns one array per size in a single reply without tools or scoring feedback.
       • Iterative WSP. We retain both original information conditions. At each active size, Astra
         receives the selected weights, exact-match counts, errors and up to three worst labeled
         examples from each of the training and development sets. The development pool contains
         256 new central inputs per sampled task and start, or indices 9–16 for the integer sequences.
         A revision replaces the current weights only when its development loss is strictly lower
         or, at equal development loss, its training loss is lower. An invalid proposal counts as a
         rejection. Each size stops when every training and development example is exact, after
         two consecutive rejections, or after three revision attempts. This is a finite stopping rule,
         not a guarantee of convergence. Requests for different cases may run concurrently. Each
         revision uses a fresh Astra session with the same task and selected weights; the prompt
         forbids tools, and we inspect the recorded events for tool use. Test inputs and scores never
         enter a revision. Appendix A.1 describes the audit and controls.

       • Gradient descent and gradient descent followed by L-BFGS. Full-batch gradient de-
         scent uses the derivative computed by backpropagation and a training-loss line search for
         up to 800 updates. From that endpoint, the limited-memory Broyden–Fletcher–Goldfarb–
         Shanno method (L-BFGS) approximates curvature with ten recent pairs of weight and gra-

         lower training loss of its two stages.
       • Trust-region least squares. Starting at the identical Xavier weights, this solver uses the
         matrix of first derivatives of individual residuals (the Jacobian) to select local steps. It
         allows up to 250 residual evaluations followed by up to ten local polishing steps accepted
         on training loss.

Appendix A.2 also reports L-BFGS directly from Xavier and from the 800-step Adam endpoint.
The primary numerical solvers fit the original training labels. A separate control fits both gradient
baselines to the entire labeled training and development pool.
The archive also scores the initial Xavier array. Astra brings pretrained knowledge of familiar for-
mulas and operates under a different computational budget. Examples-only prompts disclose the
deployment range and a task-specific graph. A match on visible information therefore controls the
experiment more narrowly than a match on prior knowledge or compute.

Evaluation. We evaluate root mean squared error (RMSE) in target units over all scalar outputs.
An exact prediction equals its reference in the standard 64-bit floating-point format (binary64),
treating both signs of zero as equal. For running sums and sorting, one example counts as exact
only if every coordinate matches. For the integer sequences we count matching indices on a single
trajectory. Metrics are computed per endpoint before aggregation across starts. The central test uses
fresh values in [−3, 3], and the outer test uses [−10, −3] and [3, 10] with both signs for signed tasks.
Positive self-power uses training inputs in [0.02, 3], central and development inputs drawn uniformly
from [0, 3] (positive almost surely), and outer inputs in [3, 10]. Each scalar evaluation has 2,048
samples per available outer side. Each arithmetic, sum or sorting test has 2,048 examples per split.
The integer sequences use unseen indices 17–32 for early transfer and 33–64 for late transfer. The
original one-shot study used 9–32 for early transfer. We preserve those scores separately because
indices 9–16 are now used for feedback. Running sums in the primary comparison keep length
six as magnitudes change. The supplement separately tests length 32. We report raw errors within
tasks. For the aggregate ranking, we average raw outer RMSE over the sizes and starts of each task
and then sum those ten task means. The supplementary plots also retain scaled errors and paired
comparisons.

Did the optimizer reach the global training minimum? For the four scalar tasks with one hidden
unit we can compute the global optimum on the supplied labels in real arithmetic. After sorting
the training inputs there are finitely many intervals for the change of slope. For each interval we
fit the two affine pieces subject to continuity, also checking the boundaries, and take the smallest
feasible loss. Appendix N gives the rational arithmetic procedure for these same training data.
This yields an independent benchmark in 12 settings. At an absolute tolerance of 10−10 above the
certified optimum, one-shot examples-only WSP reached it in 1 of 12 settings, one-shot formula-
and-examples WSP in 2, Adam followed by BFGS in 1, and trust-region least squares from Xavier
in 5. Iterative WSP reached it in 0 and 0 settings in the two information conditions, respectively;
gradient descent reached it in 0 and gradient descent followed by L-BFGS in 1. This reverses the
ordering of examples-only WSP and least squares seen in the outer-error comparisons.




What if least squares starts from the WSP weights? We took each of the 87 examples-only
WSP arrays and applied the same trust-region solver and training-loss stopping rules used from
Xavier. On the 12 certified fits this initialization brought the solver within tolerance of the global
minimum in 12 of 12. Across the full benchmark the refinement lowered training loss by more
than 10−10 in 22 settings. Among those 22, mean squared scaled outer error (with the same factor
of one half as training) increased by more than 10−10 in 13 and decreased by more than 10−10 in
nine. The 13 deteriorations also increased raw outer RMSE. The number of settings with every outer
prediction exact stayed at 30. This two-stage experiment gives the refiner an additional model call
through its starting weights. Zero extra numeric solver steps were available to the single-response
WSP methods.

5   Choosing the Architecture from Examples
The fixed-network comparison asks each method to choose weights in a supplied graph. Here we
ask Astra to choose the graph as well. Thirty independent requests cover ten tasks, with three
requests per task using the original example sets. Each request supplies the input/output pairs, input
shape and deployment domain. The prompt makes extrapolation the primary objective and asks
for economical coefficient storage, inference memory and arithmetic among comparably accurate
solutions.
The model can compose affine maps, rectified linear or hyperbolic tangent activations, multiplica-
tive gates, recurrence, convolution and attention. It chooses every node, connection and coefficient
within a maximum of 64 nodes and 4,096 stored coefficients. A convolution applies shared weights
to local input windows. Attention uses input-dependent weights to combine values. These opera-
tions support multilayer, recurrent, convolutional and attention-based architectures. Direct multipli-
cation and hyperbolic tangent can implement individual targets in this task set, so operator choice is
part of the result.
We request one graph and a short construction explanation in each final answer. These are one-shot
proposals; the calls use no tools or external numerical solver. The collector freezes all responses
before a separate evaluator scores the unseen inputs. We count every request, including malformed
graphs or nonfinite outputs. A floating-point operation (FLOP) is one scalar arithmetic operation.
Comparisons and calls to exponential or hyperbolic tangent are counted separately. Memory in-
cludes stored 64-bit coefficients and peak live tensor storage for one input under the declared sched-
ule. The memory count excludes operator-internal temporary arrays and Python or allocator over-
head; it is not a measured process-memory footprint. Appendix A.5 gives the full operator grammar,
per-trial outcomes and archived explanations. Across 30 independent architecture proposals from
input/output pairs, 28 were executable and 21 matched every original extrapolation output. All three
proposals were exact for square, hyperbolic tangent, addition, subtraction, running sum, Fibonacci
and triangular numbers. The sine proposals had median outer RMSE 7.79 × 10−16 ; sorting errors
were about 5.2 × 10−16 . Positive self-power had one executable proposal with RMSE 1.68 × 104
and two invalid proposals. Astra chose feedforward arithmetic or activation graphs and recurrent
networks; no proposal chose convolution or attention. Square used one allowed multiplication, zero
stored coefficients and 16 bytes of live activation storage. Its graph specification still occupied 109
serialized bytes. Operator choice explains this reduction relative to a ReLU-only network. The
trials establish observed implementations and resource costs, with no global architecture optimum
claimed.

6   Discussion and Limitations
The benchmark asks two questions of the same weights. The training objective measures how well
a method optimized the observations it received. Error on new input values or sequence indices
measures whether those weights continued the rule. On an unseen input no optimizer can infer a
unique continuation from central labels alone. For example, for any real number a, the functions
0 and aR(x − 3) agree on the entire central interval [−3, 3]. At x = 10 their predictions differ
by 7a. Knowledge of the task family, the architecture and Astra’s pretraining can all affect which
continuation a solver chooses.
The fixed-network comparison covers ten deterministic numerical tasks, with up to 50 trainable
coefficients. The architecture-selection experiment additionally changes the allowed graph and cost.
Continuous tasks have three sampled training sets. Integer tasks have one training set and three
initializations. Multiple sizes in the same WSP response share context. We give counts over these
fixed cases and show each size. Population claims about optimizers in vision, language or general
large-scale training require other workloads, models and budgets. The iterative method uses its
development set for both feedback and selection. Three attempts cap the cost, and a rejected proposal
can still perform better on unseen inputs. The original numerical baselines see fewer labels; we
therefore also report an intervention giving the two gradient procedures the entire feedback pool.
Neither design matches computation or pretraining. The examples-only condition still discloses
the architecture and intended range, and there is no common unit equating an Astra inference to
a gradient or Jacobian evaluation. Each hosted-model response is archived because the provider
model name alone cannot guarantee its reproduction.


                                                  8
Which sizes are known to suffice? For a one-state running sum, setting all three weights to one
returns every sum in the same addition order as the reference. Autonomous Fibonacci and triangular
generators require minimum real-arithmetic state widths two and three, respectively, for their infinite
sequences (Appendix I and the realization argument in Appendix E). For arithmetic, write t =
x1 + x2 or x1 − x2 . Even a single hidden unit can return R(t + 20) − 20 = t throughout the
bounded real domain. The large intermediate offset can change its binary64 rounding. Two units
give R(t) − R(−t) = t without that offset. For the shallow scalar architecture the best possible
uniform real error on square over [−10, 10] is 50/(w+1)2 at width w (Appendix R). A different deep
graph returned by Astra provably rounds every square correctly on the outer shell; an engineered
extension covers the full binary64 interval (Appendices Y and Z). Those architectures and proofs
give constructive bounds. They do not establish a minimal deep network for the smooth functions.
The supplementary edit theorem fixes a single output coordinate and counts how many initialized
coefficients must change to implement a recurrence (Appendix C). That question has a different unit
of cost from the primary comparison, where each solver can change every weight. The supplement
also studies a register machine, an abstract computer that updates integer registers according to
conditional instructions. Its proof concerns unbounded exact integers; the reported binary64 runs
test bounded executions (Appendix V). Neither construction is counted as a win in the optimizer
comparison.

Interpreting aggregate error and model size. The raw-RMSE sum gives each task one averaged
contribution, but the target scale determines that contribution’s magnitude. Large Fibonacci errors
dominate many totals, especially at state widths that cannot exactly represent the recurrence. A
rank under this measure differs from a rank under median scaled error. The architecture experiment
measures the outputs and resource costs of 30 proposals. Its declared operations include a direct
product and a hyperbolic tangent activation, so exactness on square and hyperbolic tangent can
follow from one primitive. Zero stored coefficients attain the nonnegative coefficient-count lower
bound. A smallest graph, smallest total storage or least arithmetic for every task would require
additional proofs. Serialized graph storage is reported even when there are no stored coefficients.

7   Conclusion
Holding the task and graph fixed makes it possible to measure three different properties of an opti-
mizer’s final weights: how well they fit the displayed examples, how close they come to the right
answer on new inputs, and whether they reproduce every reference exactly. Across the fixed-network
benchmark, iterative WSP has the smallest summed raw extrapolation RMSE among the 14 evalu-
ated pipelines. Its lower total coexists with regressions on individual tasks and an unchanged count
of 30 fully exact settings. Allowing Astra to choose the graph yields 21 entirely exact extrapolation
sets in 30 further requests, with costs determined by the permitted neural operations. Reporting the
returned weights, input/output error and execution cost together exposes these tradeoffs.

A.1   Validation feedback and additional gradient controls

What the model saw. Each revision request reproduced the original specification and included
only the active sizes, their incumbent weights, and diagnostics. For each size and split the model
received the scaled loss, raw RMSE, whole-example exact count, and at most three non-exact inputs
with the largest absolute scaled error on any coordinate. For each of those inputs it saw the target and
current prediction. The 256 central development inputs were fixed within task and start and shared
across sizes and prompt conditions. Integer indices 9–16 instead extended the original nine labels.
Original one-shot replies, new prompts, replies, decisions and final vectors are retained. Appendix X
is a different experiment that allows a circuit description to change.

Stopping and selection. The collector made 161 revision requests after the original 60 model
calls. Their recorded median latency was 51.7 seconds per request, with 198,446 output tokens
in total; requests for different tasks ran concurrently. These requests produced 332 size-specific
proposals, of which 217 were accepted; one width-16 square proposal had the wrong number of
coefficients. None of the 161 requests used tools. The 174 size-by-condition trajectories share
requests within an original task, start and prompt condition. Of those trajectories, 60 were exact
before any revision. At the end, 60 had stopped on exact training and development outputs, 33
after two consecutive rejected proposals, and 81 at the three-attempt cap. After all selections were
frozen, a separate evaluator reconstructed the feedback from training and development data, checked
every decision against the saved replies and then scored the selected weights. Table 7 follows all
87 settings per condition through each revision opportunity. The cap limits what we can conclude
about additional rounds.

What if gradient descent can use all feedback labels? We separately fit both gradient procedures
from the same Xavier start using the original training observations pooled with every feedback label,
keeping both optimizer budgets and the test sets fixed. This gives the gradient solver 268 labeled
examples per sampled task or 17 integer indices; Astra saw diagnostics and selected examples from
that pool. The baseline therefore has access to more individual labels than Astra. With examples
only, iterative WSP had lower outer RMSE than pooled-data gradient descent in 78 settings and
than its L-BFGS refinement in 80 (out of 87). The pooled procedures matched every outer reference
in 0 and 0 settings, respectively. Machine-readable files include training, feedback, independently
held-out central or early, and outer scores for both pooled endpoints.

Independent test draw. After the weight selection was frozen, we generated a second set of cen-
tral and outer inputs using a new random seed. On the 69 settings with sampled inputs, the iterative-
versus-one-shot outer RMSE comparison was 22 lower, 23 tied and 24 higher with examples only,
and 20 lower, 23 tied and 26 higher with the formula supplied. The 18 integer settings have fixed
target indices and are not repeated as independent draws. The companion data include the scores
from both draws.

Why did iterative WSP lose extrapolation accuracy? The prompts explicitly asked for predic-
tion beyond the observations. In the original eight-task prompt, Astra was told, Among similarly
fitting solutions, aim for exact outputs on unseen inputs across the stated domain. The arithmetic
prompt gave the equivalent instruction for equally good training fits. Each revision repeated the
original prompt and added, Seek a rule that also generalizes to examples not shown. These in-
structions made extrapolation a secondary aim. The revision selector accepted weights with lower
development loss, using training loss only to break a tie. That selection criterion rewards accuracy
on the central interval and permits a worse continuation outside it.
The stored coefficients show the resulting tradeoff on square. In all six width-16 square networks,
across both information conditions and three starts, the original reply put three or four changes of
slope outside [−3, 3]. After iteration, every change of slope lay inside [−3, 3]. Each revised network
therefore used a single affine continuation on either extrapolation interval. For the examples-only
run at seed 164, the rightmost change of slope moved from 7.4 to 2.419 and the right-tail slope
fell from 17.4 to 5.3915. At input 10, the reference is 100, the original network’s real-arithmetic
prediction is approximately 100, and the revised prediction is 46.6765. The selected development
RMSE fell from 0.396 to 0.0145, while outer RMSE rose from 1.22 to 24.0. This coefficient-level
analysis identifies the mechanism of that failure. The aggregate effect of the wording and selection
rule would require a controlled ablation.

A.2            Gradient descent and limited-memory optimization

This subsection retains the original training-only gradient comparisons. Its early integer diagnostic
uses the original indices 9–32. For a comparison with iterative WSP on untouched indices 17–32,
see Table 5. These fits use the same nonconvex networks, initial weights, training observations and
loss as the main comparison. Plain full-batch gradient descent starts from Xavier and takes at most
800 updates. At each update it tries step size one and halves it until the training loss decreases
sufficiently. Limited-memory Broyden–Fletcher–Goldfarb–Shanno (L-BFGS) uses the most recent
ten pairs of changes in weights and gradients to approximate curvature. We run it with no parameter
bounds for up to 1,000 iterations. Its reported endpoint has the lowest training loss among the
supplied starting point and its accepted iterates. Selection uses training loss throughout.
We start L-BFGS from three separate points: the original Xavier weights, the gradient-descent end-
point, or the endpoint after 800 adaptive moment estimation (Adam) updates. The Adam checkpoint
in Table 8 is scored before refinement. The separate Adam–BFGS baseline applies full-memory
BFGS after Adam. Each additional fit uses derivatives of the empirical loss obtained by backpropa-
gation through the network. The complete records include optimizer termination, per-setting scores
and fitted weights.

Allowed operators are affine maps, rectified linear units (ReLU), hyperbolic tangent, sigmoid, ele-
mentwise addition and multiplication, static tensor indexing and concatenation, reshape, transpose,
matrix multiplication, softmax and one-dimensional convolution. Optional recurrence repeats a
shared cell. This library permits multilayer perceptrons, recurrent neural networks, convolutional
neural networks and attention networks, as well as multiplicatively gated arithmetic graphs. It
bounds every proposal at 64 nodes and 4,096 scalar coefficients. A tanh node directly implements
hyperbolic tangent, and a multiplication node directly implements square. Both operations therefore
affect capacity and the appropriate interpretation of comparisons with the fixed ReLU architectures.
Each floating-point operation (FLOP) is a scalar addition, multiplication or division. Dot products
count every multiply and accumulation, including fixed zeros and ones. Comparisons and transcen-

bias, matrix entry and initial-state value. Each coefficient takes eight bytes. Peak workspace counts
live binary64 input, state, intermediate and output buffers under the interpreter's dependency-based
lifetime rule. Graph outputs are materialized. Python, allocator and matrix-library workspaces are
excluded. Serialized executable JavaScript Object Notation (JSON) reports the full graph-file size,
including topology and numeric literals. This serialization metric is separate from runtime memory.
For recurrence, costs use one example starting from the initial state; the listed worst case is index 64
or a six-element stream. A comparison of costs therefore requires the same operations, precision,
input length and memory accounting.

square, tanh and addition proposals attain that bound in this operator library. The square graph also
uses one arithmetic multiplication. A nonconstant scalar output requires at least one stored output
scalar under the materialized-output convention, or eight bytes in binary64. The observed 16-byte
square workspace includes input and output. These simple bounds provide no certificate that the
other proposed architectures minimize coefficients, workspace or arithmetic.

A.8   Nonconvexity witnesses for the fixed networks

How we checked nonconvexity. A convex training loss at the midpoint of any two weight vectors
is at most the average of their losses. We check this inequality on the actual training examples. A
linear recurrent network is linear in its input for fixed weights, but its input and readout weights
multiply each other. For example, switch off the state transition and use just one state coordinate.
Let its input weight be a and its readout weight be b. Each tick then outputs ab times the current
input. The pairs (a, b) = (1, 4) and (4, 1) have the same product, 4, while their midpoint (5/2, 5/2)
has product 25/4. Reversing both readout signs if needed makes increasing the magnitude of this
product increase the squared training loss. To see why, the initial slope of the loss as a function of
the product at zero can have either sign. Choose the direction with nonnegative slope. Along that
direction the loss is a strictly convex quadratic because at least one observed input is nonzero. The
midpoint therefore has strictly greater loss than either endpoint.
The same construction works with the bias and readout of one active scalar rectifier, the input and
output weights of one sorting block, or the initial state and readout of an autonomous sequence
generator. All unused paths can be set to zero. In the sorter the original input still passes through its
fixed identity connection. For the two autonomous tasks, a transition of one on the active coordinate
keeps the output constant across the observed indices. Exact rational evaluation of the stored training
data certifies 36 smooth-function settings (four tasks, widths 1, 4 and 16), six running sums (widths
1 and 2), nine four-input sorters (four, five or six blocks), and 18 sequence generators (Fibonacci
widths 1–3 and triangular widths 2–4). Each size uses three starts. The sequence generators share
their training labels across starts. Replaying the training code gives midpoint violations from 0.872
to 16.014 in units of training loss. The original 18 affine arithmetic settings and three memoryless
sums minimize a weighted sum of squares of affine functions of their weights, a convex quadratic.
Addition and subtraction on trainable rectifier networks of widths 1, 2 and 4 are a separate 18-setting
experiment with their own midpoint certificates. A midpoint violation establishes the shape of the
objective. Whether a solver reaches a better fit is a separate measurement.

B    Numerical conventions for the additional studies
The primary benchmark uses the named NumPy numerical-library operation or an integer recurrence
converted to binary64 as its reference. In the supplementary elementary-function experiments, the
MPFR library for multiple-precision floating-point computation supplies correctly rounded math-
ematical values [22]. Correct rounding returns the representable number nearest the exact mathe-
matical result, choosing the one with an even last significand bit in a tie. The significand holds the
significant binary digits and the exponent gives their scale. Normal binary64 numbers have 53 sig-
nificant bits. A dyadic rational is an integer divided by a power of two: for example, 3/8 is exactly
0.011 in binary. Every finite binary64 number has this form.
A unit in the last place (ULP) is one step in the last stored digit at a given scale [7]. We measure
ULP distance by counting adjacent representable values, treating both signs of zero as equal. At 1,
for example, the next larger number is 1 + 2−52 and the next smaller number is 1 − 2−53 . Both
have distance one under this convention. The mean scaled absolute error averages each absolute
prediction error divided by the larger of one and the absolute reference value. A parameter slot
stores one scalar even if it is zero. An edit changes one stored scalar from its initialized value. An
operation is an executed arithmetic or activation step in the stated graph. A real-arithmetic proof
assumes exact algebra; a binary64 proof specifies where rounding occurs.

C    Why fitting a short running sum can fail on the next step
A recurrent neural network (RNN) carries a state vector from one input to the next. Let d ≥ 1 be the
number of state coordinates. At step t ≥ 1 let xt be the scalar input, ht the column of d real state

E    Proof of Theorem 1
We count changes to the D = d2 + d real entries of the transition matrix A and input column b of a
width-d linear recurrent network. The output row c reads one fixed state coordinate. Renumbering
the coordinates preserves edit counts, so take c = e⊤    1 , where e1 is the first standard basis column
and ⊤ denotes transpose. Here, the real numbers form the field of coefficients for every calculation
in the proof. A unit impulse is input 1 on the first tick and 0 thereafter. Index its desired scalar
outputs by g0 , g1 , . . . and fix the number H ≥ 1 of required outputs. For a positive integer s, define
the observation matrix Os (A) by stacking the s rows c, cA, . . . , cAs−1 . The rank of a matrix is
the number of independent columns (equivalently, rows). Its kernel comprises the vectors that it
sends to zero. The product of Os (A) with b gives the network’s first s impulse outputs. Write
g0:s−1 = (g0 , . . . , gs−1 )⊤ .

Fix the smallest-degree monic polynomial p for which p(S)g = 0 at all indices. Its degree r is the

constant on each antidiagonal. The leading r-by-r Hankel matrix Gr = (gi+j )0≤i,j<r is invertible.

Hankel matrix after the first r obey the same recurrence, giving overall rank r.

Controlling the characteristic polynomial. Call (c, A) observable if Od (A) has rank d, so the
first d scalar observations distinguish all initial states. Let I be the d-by-d identity, let χA (z) =

observability holds with probability one under the initialization in Theorem 1.

Constructing an edit. If H ≤ d, select H linearly independent columns of OH (A). Holding the
remaining entries of b fixed, solve the resulting invertible system for the selected entries of the new
input vector b′ to obtain OH (A)b′ = g0:H−1 . This takes at most H edits.
For H > d, put k = H − d. Seek a monic degree-d polynomial q such that the first k terms
of q(S)g vanish. These linear equations in the coefficients of q are consistent because a monic
degree-d multiple of p exists. Their k-by-d Hankel coefficient matrix has rank min(k, r), since
it contains the first min(k, r) rows of the invertible Gr and the infinite matrix has rank r. The
bijection above lets us impose the equations on q = χA+uc with the same rank in u. Select that
many independent columns of this linear system and use just their coordinates of u. Then solve
Od (A + uc)b′ = g0:d−1 , using at most d more edits. The Cayley–Hamilton identity says a square
matrix satisfies its characteristic polynomial. Consequently the network impulse outputs satisfy the
recurrence q, and so agree by induction with the target through the first H outputs. If k ≥ r, the first
r terms of q(S)g vanish, and the recurrence p propagates those zeros to all subsequent terms. The
total cost is at most d + min(k, r).

Bounding the size of the solution set. Codimension is the ambient dimension minus the di-
mension of the subset. We show that the set of (A, b) realizing the prefix has codimension at
least min(H, d + r), allowing for unobservable realizations. Let m = rank Od (A), and write
U = ker Od (A) for the subspace of initial states invisible to the output. Because c ̸= 0, we have
1 ≤ m ≤ d. The subspace U has dimension d − m, lies in ker c, and satisfies AU ⊆ U by Cayley–
Hamilton. The family of possible subspaces U of this dimension inside the (d − 1)-dimensional
space ker c has dimension (d − m)(m − 1). Locally such a subspace is the graph of a linear map
between spaces of dimensions d − m and m − 1. For fixed U , the condition AU ⊆ U forces a block
of m(d − m) entries to vanish in a basis adapted to U . Subtracting the freedom to choose U leaves
codimension at least d−m. Identifying states that differ by an element of U gives an m-dimensional
quotient space. Denote its induced transition and output by Ā, c̄. This quotient is observable.
If m ≥ H, the first H observation rows are independent. Once an observation row belongs to the
span of earlier rows, multiplying the relation by A prevents every subsequent row from increasing
that span. Hence the H impulse equations impose H constraints on b for fixed A, as required. If
m < H, the first m impulse equations impose m independent constraints on b, leaving d − m free
coordinates. Put k = H − m. The other equations require q = χĀ to satisfy (q(S)g)i = 0 for
0 ≤ i < k. The coefficient matrix B = (gi+j )0≤i<k, 0≤j<m has rank rank B. When consistent,
these equations impose that many independent conditions on Ā. To see this, perturb it by ūc̄ for
a quotient-space column ū. The characteristic coefficients vary freely by the bijection above, and
every such perturbation lifts to a matrix that preserves U . Thus the total codimension for this value
of m is at least (d − m) + m + rank B = d + rank B.
If m ≥ r, then rank B = min(k, r) and d + rank B ≥ min(H, d + r). If m < r and k ≥ r,
propagation of the initial zeros of q(S)g would give an annihilating polynomial of degree m < r,
contradicting the definition of r. Finally if m < r and k < r, deleting r −k rows and r − m columns
of Gr leaves B, so rank B ≥ k + m − r = H − r. Then d + rank B ≥ H, as required.

From dimension to scalar edits. Fix a set of s coordinates allowed to change. Initial networks
which can reach the prefix solution set lie in its sum with the s-dimensional subspace supported
on those coordinates. The solution set is defined by polynomial equations in real parameters. Its
sum with this subspace is semialgebraic, meaning that it can be described using finitely many real
polynomial equalities and inequalities and Boolean combinations. Its dimension is at most D −
min(H, d + r) + s because it is the image under addition of a product of that dimension at most. If
s < min(H, d + r), this is less than D, so the sum has Lebesgue measure zero. There are finitely

F    A comparator that preserves binary64 operands
A comparator takes two inputs and returns their smaller and larger values in that order. Let a, b be
finite binary64 inputs in [−10, 10], let R(t) = max(t, 0) be the rectified linear unit, and take fixed
constants K = 2537 , M = 10. Round each displayed operation separately to the nearest binary64
value, choosing the one with even last significand bit at a tie. Gradual underflow retains reduced-
precision values below the smallest positive normal number. Numerical equality identifies the two
signed zeros.
First extract the positive difference r, amplify it to u, and compute the auxiliary signals v, B, S.
Then compute the keep and swap selectors k, s, respectively, in this order:
 r = R(a − b),     u = Kr,      v = u − R(u − 1),      B = 1 − R(1 − u),       S = 1 − R(1 − Kv),
                              k = R((1 − B) − S),          s = 1 − k.
For an operand x and an enable bit g ∈ {0, 1}, set G(x, g) = R(x−M (1−g))−R(−x−M (1−g)).
The comparator returns (G(a, k) + G(b, s), G(a, s) + G(b, k)), reusing the shifts M k, M s.
When a ≤ b, u = B = S = 0 and k = 1. When a > b, the rounded positive difference is at
least the smallest representable positive value 2−1074 . For 0 < u ≤ 1, v = u and Kv ≥ 1, hence
S = 1. For u ≥ 1, B = 1. In that case the rounded value of u − 1 lies between u − 2 and u, since
u itself is representable and is one unit of absolute distance from the exact difference. Therefore
0 ≤ v ≤ 2, which also shows that the product Kv remains finite. Both B, S lie in [0, 1] and at least
one equals one, so k = 0. For g = 1 the gate G returns the original operand, while for g = 0 both
rectifiers vanish. Composition along a sorting schedule therefore preserves all numerical operands.
The stored comparator contains 43 edge weights and seven biases, with Xavier initialization for the
weights and zero initialization for the biases.

K    Experimental detail and reproducibility
Hardware and arithmetic. The initial suite used binary64 arithmetic on an Apple M5 central
processing unit. For the initial scalar experiments, the environment used Python 3.13.12. The main
sequence, frontier and archive scoring environments used Python 3.12.12. Both used NumPy 2.5.4
and the macOS Accelerate implementation of the Basic Linear Algebra Subprograms (BLAS), with
SciPy 1.18.1 for optimization. Exact rational computations, which retain integer numerators and
denominators, use Python’s Fraction. Stream sums use successive rounded additions in temporal
order. In this suite the transcendental labels are the platform NumPy results. Tests compare to that
implementation. Correct rounding of transcendental functions is a separate question. Re-running
with a different BLAS or math library can affect last bits and optimizer paths.

Initialization and budgets. Let nin and nout be the input and output coordinate counts of a
layer (its fan-in and fan-out). Xavier initialization draws each weight uniformly between the

count edits separately from either. Scalar widths are 0, 1, 3, 7, 15, 31, 63. Compact tent depths are

Let tj be an interior knot and sj−1 , sj the slopes of the adjacent secants. The corresponding hinge
has input weight wj = 1, bias cj = −tj and output weight vj = sj − sj−1 . A linear skip carries the
leftmost secant. No samples from the outer test arrays enter training or checkpoint selection.
Adam, the adaptive moment estimation optimizer, updates weights using running estimates of the
first and second moments of the training gradients. The quasi-Newton optimizer BFGS is named
for Broyden, Fletcher, Goldfarb and Shanno. Its limited-memory version with support for bounds is
L-BFGS-B. A minibatch is a sampled subset of training examples used for one update. The shallow
scalar gradient runs use three seeds (11, 22, 33), 1,024 in-range training points, 500 minibatch
Adam updates of size 64 with learning rate 0.01, then at most 250 full-batch L-BFGS-B iterations.
We retain the endpoint with smaller training mean squared error (MSE), the mean of squared scalar
prediction errors. The compact deep square runs use 300 Adam updates and at most 100 L-BFGS-B
iterations. Inner scoring uses 4,096 points and outer scoring uses 4,096 per sign where defined. Tanh
polishing uses ten least-squares solves with the full analytic Jacobian. For the affine control let X
collect the training input rows and N count the rows. The gradient step size is the reciprocal of the
largest eigenvalue of X ⊤ X/N . Phase folding uses six rectifiers to implement the piecewise-linear
triangular wave arcsin(sin x), where arcsin is the inverse sine taking values in [−π/2, π/2], on the
declared envelope. Its readout uses a least-squares fit on folded central examples. Identical-shape
end-to-end training yields median shell mean absolute error (MAE) 3.169.
Sequence sweeps use widths 1, 2, 4 for rolling sum and 1, 2, 3, 4 for the two autonomous sequences.

five untied gates and an additional full tied model. Training uses 256 inner streams of length eight or

integer trajectory, first nine labels for training. Each of the 15 configurations uses five independent

1,000 iterations. Objective is half mean squared residual. For a target sequence value gn at index
n, integer-sequence residuals are divided by max(1, |gn |) before squaring. We checked reverse-
mode gradients, obtained by propagating output derivatives backwards through the graph, against
centered finite differences obtained from small positive and negative parameter perturbations. We

L    Signed indices and the negative shell
The central integer set is {−3, . . . , 3}. The outer sets are {−10, . . . , −4} and {4, . . . , 10}. For
negative binary64 inputs, each noninteger has a reduced rational representation with an even de-
nominator. Raising a negative base to that exponent has no conventional real value. On the 21
integers from −10 to 10, by contrast, nn is rational, with 00 = 1 by continuity from the positive
side. NumPy’s result equals the once-rounded rational reference at every index. A 572-slot rectifier
lookup uses one triangular hat per integer. A hat equals one at its own integer and zero at all other
integers. Setting its readout coefficient to the target value matched all seven central integers, seven
negative-shell integers and seven positive-shell integers. Among the linear output weights that fit
the seven central labels, the solution of smallest Euclidean norm in the same feature map missed all
14 shell integers. On the seven negative and seven positive outer integers, WSP gave RMSE zero for
both signs. BP from a Xavier readout on the same frozen hats gave outer RMSE .314 and 3.78×109 ,
respectively. The minimum-norm readout instead gave .00148 and 3.78 × 109 . Each central-only fit
missed every outer index. The full WSP lookup stores the specified answers.
For integer index n, let Fn denote the Fibonacci value and Tn = n(n + 1)/2 the triangular value.
For n > 0 the signed Fibonacci convention is F−n = (−1)n+1 Fn . The input consists of |n| unit
ticks and a supplied sign selecting the forward or inverse transition. Each model stores forward
and inverse transition matrices, an initial state, and a readout. The width-two Fibonacci and width-

three triangular models therefore use 12 and 24 scalar slots. A direct write and a rational recurrence

Observed sizes versus certified minima. The minimum state widths are one for the driven linear
accumulator and two and three for the homogeneous, autonomous Fibonacci and triangular genera-
tors, respectively. For four-input real sorting, 5 ReLU gates are both sufficient and necessary, while

The shallow square has a sharp real-error frontier at every width. For the compensated deep square,

M     Protocol for the preliminary ten-task comparison
Each request provided one task, its central examples and three candidate architectures with their
initialized coefficients. The response had to supply one complete array of replacement weights
for each architecture. We crossed ten tasks, three random-number seeds (164, 317, 583) and two
information conditions, yielding 60 independent calls and 180 arrays. Three arrays in one response
share a prompt. A seed changes the initialization and the sampled examples, except that the two
canonical number sequences always use the same indices. The Formula and examples condition
supplied the task definition and central input–output pairs. The Examples only condition omitted the
formula and task name but retained informative choices of architecture, indexing and deployment
range. Every saved command-line interface trace recorded one response and zero tool actions. Each
measurement uses the first returned array.
For the four smooth targets, the choices were one, four or 16 scalar hinges with an affine skip from
input to output (5, 14 or 50 adjustable scalars). For addition and subtraction, the three models saw
only the first input, both inputs without bias, or both inputs with a bias (1, 2 or 3 scalars). For
running sum, the models were a memoryless linear map or recurrent networks with one or two
hidden coordinates (1, 3 or 8 scalars). For sorting, let h ∈ R4 denote the current four values and let
v, w ∈ R4 be learned columns. A block updates h to h + v ReLU(w⊤ h), using eight unconstrained
coefficients. Four, five or six such blocks use 32, 40 or 48 coefficients and permit different routing
in every block. For a sequence generator of width d, the adjustable entries are a d-by-d transition,
d initial values and d readout weights. The tested widths were 1, 2, 3 for Fibonacci and 2, 3, 4 for
triangular numbers. Table 15 selects the 16-hinge smooth network, the two-input affine map, and
the smallest known sufficient real-arithmetic configurations for the remaining tasks.
The WSP and backpropagation conditions received 12 central labeled examples per task, except for
the canonical sequence generators, which used the nine indices 0, . . . , 8. Input lists had length four
for sorting and six for sums. Fixed-length tests held the lengths constant and changed the input
magnitudes. A scalar shell side contributed 2,048 inputs, and positive self-power used only the right
side. Each vector test comprised 2,048 independent examples. Sums also used separate length-32
tests on central and outer values. Canonical number sequences have an early transfer set at indices
9–32 and a later outer set at 33–64. An exact percentage there counts correct individual numbers
along one trajectory. For a vector or stream, exactness requires equality at every coordinate or tick
within that example.
Numerical labels come from the stated NumPy binary64 operation on those inputs. The separate
smooth-function studies use the GNU MPFR library for correctly rounded multiple-precision arith-
metic, which supplies an independent reference for transcendental functions. Training used 800 full-

batch updates of adaptive moment estimation (Adam) and up to 1,000 Broyden–Fletcher–Goldfarb–
Shanno (BFGS) iterations using an approximate inverse curvature matrix. For each scalar reference
y, the residual is the prediction minus y, divided by max(1, |y|). Training minimizes half the mean
of the squared residuals. Each gradient at initialization was checked by finite differences, compar-
ing it to a symmetric small perturbation of each parameter. The WSP prompt prioritized the largest
absolute scaled residual. To compare both methods under one criterion, Appendix N scores all re-

A global optimum against which to judge a local solver. For a single hidden scalar ReLU with
affine skip, the model is a continuous two-piece line. Let a, b be the skip slope and intercept, let t be
the hinge location and v its change in slope, and let (u)+ = max(0, u). Its output at input x is ax +
b + v(x − t)+ . A hinge of the other orientation is absorbed by the affine skip. Sort the observations.
For each split with at least two sites on each side, let ℓ1 , ℓ2 denote independent weighted least-
squares lines fitted to the observations on the left and right, with weights 1/ max(1, |yi |)2 . If the
lines intersect inside the gap, their joint optimum is feasible. Otherwise an optimum on that gap
occurs at a boundary, unless the two lines coincide. To see this, let D(x) = ℓ1 (x) − ℓ2 (x). If l, r
are the adjacent sample locations on either side of the gap, intersection is equivalent to D(l) ≤ 0 ≤
D(r) or D(l) ≥ 0 ≥ D(r). Each alternative is a closed polyhedral set in the four line coefficients.
Its quadratic minimizer is either the unconstrained fit or lies on an equality boundary, which fixes
the knot to a sample. If one side contains only one site, a line through that site and the adjacent knot
attains its unconstrained one-site fit. We therefore also solve at all interior sample knots and include
the global affine fit. We evaluate these small linear systems and losses over exact rationals using
the stored binary64 inputs and labels as rationals. This certifies the optimum for the real-arithmetic
model. Minor last-bit differences arise when evaluating its coefficients in binary64. We also solve
the weighted normal equations for 21 linear cases and construct interpolants on the 12 width-16
smooth cases, for 45 analytical comparison writes in total.

P    Passive training of recurrent networks
Recurrent cells and task interfaces. Passive training here means learning from fixed central
input–output examples. We compare a recurrent neural network (RNN) that uses the hyperbolic
tangent tanh(a) = (ea − e−a )/(ea + e−a ) with a gated recurrent unit (GRU). At integer tick t,
let xt be the input vector, let ht ∈ Rd be the hidden state of width d, and let v ∈ Rd , by ∈ R
be the readout weights and bias. Both cells predict ŷt = v ⊤ ht + by . The tanh cell applies tanh
coordinatewise to the sum of affine transforms of xt and ht−1 .
For the GRU, use subscripts r, z, n for reset, update and candidate, respectively. For each subscript
j, let Ij (x) = Wj x + bj and Hj (h) = Uj h + cj be learned affine maps to d coordinates. The
parameters Wj , Uj are matrices and bj , cj biases. The sigmoid σ(a) = 1/(1 + e−a ) converts a real
input, or logit, into a gate between 0 and 1. With ⊙ denoting coordinatewise multiplication, the reset
and update gates rt , zt , the candidate h̃t , and the updated state are
             rt = σ(Ir (xt ) + Hr (ht−1 )),             zt = σ(Iz (xt ) + Hz (ht−1 )),
             h̃t = tanh(In (xt ) + rt ⊙ Hn (ht−1 )),    ht = (1 − zt ) ⊙ h̃t + zt ⊙ ht−1 .
For running sums it reads one scalar per tick, starts from zero and predicts the sequential binary64
sum after each update. For Fibonacci and triangular sequences we draw two initial values (a, b) for
each example and train on a family of trajectories. Fibonacci starts at (y0 , y1 ) = (a, b) and follows
yt+2 = yt+1 + yt . In the triangular family let ut denote the increment to add at tick t. We initialize
(y0 , u0 ) = (a, b) and update
                                  (yt+1 , ut+1 ) = (yt + ut , ut + 1).
Let E be the learned d-by-2 input encoder matrix and e its bias column. Both models initialize
h0 = tanh(E(a, b)⊤ + e), read it out at tick zero and receive zero inputs thereafter. The classical
sequence in each family uses (a, b) = (0, 1). Sorting a list of length T takes 2T ticks. The cell first
reads (xi , 0) for each list element, then receives (0, 1) on each of T emission ticks. The readout
must emit the sorted values in order. Only the final encoder state carries information about the list
into emission.

Necessary state dimensions over the reals. Define the Jacobian of a map as its matrix of first
derivatives, and its rank as the number of independent output directions. The map from (a, b) to the
first two outputs has Jacobian determinant one in both seeded tasks. It factors through h0 ∈ Rd , so
the chain rule requires d ≥ 2 for exact reproduction on an open set of seeds. For sorting, restrict
the inputs to the open region x1 < · · · < xT . The desired output map is the identity there and has
Jacobian rank T . All emission ticks factor through one state, so d ≥ T is necessary. This accounts
for the width-four boundary for the four-input encoder. The tanh and GRU maps are smooth, while
real sorting has a kink when two coordinates cross. Width alone therefore cannot certify continuum
sorting for these cells. Both rank arguments concern exact real maps on open sets. Finite binary64
tests have different implications.

Theorem 2 (Lattice square capacity). For any D ∈ {D0 , Din , Dout } of cardinality N , the maximum

changes its output by at most the magnitude of a change in its input, so the hidden error is at most
2−39 . The output-weight product has magnitude below 218 and its rounding costs at most 2−34 .

Take three sites x1 < x2 < x3 within one affine piece. The secant, the affine line joining the two
outer square values, exceeds x22 at x2 by (x2 − x1 )(x3 − x2 ) ≥ 1/256. For a common error bound

For attainment, choose the first min{N, 2(w + 1)} sorted sites and pair them consecutively. If the
selected count is odd, use the last two sites for the final pair, sharing its first site with the preceding
pair. Write the secant through each pair. Consecutive slopes strictly increase. For disjoint pairs each
secant lies below the square on the other pair, so their intersection lies in the intervening gap. For
the overlapping pair it is the shared site. Store the first secant in the skip and, at each intersection t,
add the slope increment times ReLU(x − t). This realizes the desired secant on every selected pair.
On a uniformly spaced run, an intersection between disjoint pairs is the midpoint of the intervening
gap. The outer set has 112 sites on each side, so the secants on either side of its central gap meet at
zero. Every knot is a multiple of 1/32, every slope increment a multiple of 1/16, and every secant
intercept a multiple of 1/256. The coefficients obey the cap. Each intermediate on a grid site is a
multiple of 1/512 of magnitude below 226 , and therefore each operation is exact in binary64. For
larger widths, append hinges with zero output weight. This construction reaches all sites by width
160 even for the largest set, so the trivial upper bound N covers every remaining width.

from Section 3 on [−L, L]. Its uniform error on square is the supremum (least upper bound) of

smallest possible uniform error over real weights is exactly L2 /[2(w + 1)2 ]. To see the lower bound,
take a segment of length ℓ on which the network is affine. For a function on its two endpoints and
midpoint, the second difference is its endpoint sum minus twice its midpoint value. It is zero for
an affine function and ℓ2 /2 for square. If all three errors have magnitude at most η, their second
difference has magnitude at most 4η. At least one segment has length 2L/(w + 1) or greater.
Conversely, connect equally spaced square values by lines and shift the result down by half its
largest interpolation error. This piecewise-affine function, or spline, attains the bound. At L = 10,
a uniform tolerance of 0.01 first becomes possible at 70 hinges. A fixed absolute tolerance of 2−52
requires 474,531,328 hinges. Binary64 step sizes vary with the input and output magnitude.
A separate threshold holds for binary64 arithmetic. Limit all coefficient magnitudes to 128 and eval-
uate products and sums in the fixed order of Appendix Q, rounding after each operation. Exactly
1,280 hinges (3,842 slots) are necessary and sufficient for correct square outputs on all 2,561 equally
spaced sites in [−10, 10] at spacing 1/128. The attaining network misses all 2,560 midpoints be-
tween those sites. Any network in this class that is correct on the entire binary64 interval must also
be correct on the grid. The result gives a lower bound for that class and an exact minimum for the
grid.

Sorting without perturbing an input. For each ordering of four distinct real inputs, sorting ap-
plies a different permutation of the four coordinates. On the region corresponding to that ordering
the derivative matrix (Jacobian) is the associated permutation matrix. A feedforward affine/ReLU
graph with g scalar ReLUs has at most 2g patterns of active units and therefore at most 2g distinct
Jacobians on open regions. As 4! = 24, at least five gates are necessary. Five suffice over the reals:
a comparator sorts a pair (a, b) by forming t = R(a − b) and returning (a − t, b + t). Applying
it to five prescribed pairs sorts four inputs [2]. Subtracting a rounded difference can perturb one
operand in binary64. In the fixed-schedule outer test this WSP sorter matched 1,105 of 2,048 lists
with RMSE 5.12 × 10−16 .

coefficient uses. Appendix F proves that the comparator returns both original numerical values in

Circuits and reference values. We designed one circuit for the sine of a scalar input x in radians
on [−16, 16] and one for the self-power function x 7→ xx on [0, 128], setting 00 = 1 by continu-

ity. Each design uses the formula and its domain. In this engineered weight-space programming
(WSP) condition, we set the weights of each graph before evaluating any test input. The circuit is a
directed acyclic graph, meaning a list of operations in which each result depends only on earlier op-
erations. Its operations are scalar affine maps (weighted sums plus offsets) and rectified linear units,
ReLU(v) = max(0, v) for scalar v. We checked that at least one argument of every multiplication
depends only on fixed coefficients. The graph uses separate binary64 operations, each rounded to
nearest with ties to even. This fixes the order of addition and multiplication and permits subnormal
results, the values spaced 2−1074 apart below the smallest positive normal number 2−1022 .
Our mathematical reference is the exact function rounded once to binary64. We computed it with

tions [22], at 53 significant bits and cross-checked challenge values by rounding higher-precision
evaluations. NumPy, the numerical library used in the earlier tests, differs from MPFR on 321 of

representable steps between prediction and reference, identifying signed zeros.

Choosing a bit using rectified linear units. Let r be a nonnegative binary64 remainder, k an
integer exponent used by the circuit and a = 2k a normal threshold. Its nearest smaller binary64
value is a − 2k−53 . Define the threshold gate
                           Bk (r) = ReLU 1 − ReLU 253−k (a − r) .
                                                                  

At r ≥ a the inner rectifier returns zero. At r < a the gain 253−k scales the difference to at least one.
Thus the output is precisely the bit for the decision r ≥ a. To copy a signed value v only when a bit
b equals one, choose a bound M ≥ |v| and evaluate ReLU(v −M (1−b))−ReLU(−v −M (1−b)).
The result is v when enabled and zero otherwise. The circuit uses these operations to select terms
of known sums. Its two-word variant represents an intermediate by the sum of a leading binary64
value and a smaller correction. Compensated arithmetic retains part of the rounding error of each
sum or constant product in that correction [4].

Sine. Starting with angle zero, we store its sine and cosine, zero and one. We inspect the powers
2k in |x| from k = 4 downward. Whenever Bk selects a power, we subtract it from the remainder
and apply the sine and cosine angle-addition formulas for a rotation of 2k radians. Its sine and cosine
are coefficients computed before inference by Taylor series for angles up to one radian and angle
doubling for larger angles. The 83-stage graph ends at k = −78 and restores the sign of x. For
|x| ≤ 2−26 it returns x directly, because the bound |x − sin x| ≤ |x|3 /6 is below half the distance
to the next binary64 value toward zero.

Self-power. For x ≥ 2−64 , choose an integer exponent e and fractional remainder u with x =
2e (1 + u) and 0 ≤ u ≤ 1. Write log for the natural logarithm. At fractional digit j, starting
at j = 1, let d = 2−j . When the leading word of u reaches d, multiply u − d by the stored
coefficient 1/(1 + d) and add the stored log(1 + d) to a running logarithm initialized at e log 2. The
identity (1 + u)/(1 + d) = 1 + (u − d)/(1 + d) explains the update. After the last digit, add the
remaining u as a first-order approximation to log(1 + u). Next form y = 1 + x log x by adding
scaled copies of that logarithm for the selected input bits. Finally, start at exp(−1), where exp is
the natural exponential, and multiply by the stored exp(2k ) for each selected bit of y. The exact-
arithmetic identity is exp(−1) exp(y) = xx . For x < 2−64 the circuit returns one. These digitwise
logarithm and exponential methods have precedents in elementary-function algorithms (Bajard, Kla
and Muller, 1994).

T    Computing the hyperbolic tangent with affine maps and rectifiers
For a real input x, the hyperbolic tangent is tanh x = (e2x − 1)/(e2x + 1), with e the base of the
natural logarithm. The native one-neuron control in the earlier controls (Appendix I) reproduces
the NumPy library’s implementation. Here both NumPy and a weight-space programming (WSP)
circuit are compared with the mathematical function correctly rounded by MPFR. The WSP circuit
receives the formula and the domain [−10, 10].

Building a ratio from the input bits. For an integer exponent k, set the angle δ = 2k . Be-
fore inference we compute the coefficient tk = tanh δ at 256-bit precision. We use tk =
expm1(2δ)/(2 + expm1(2δ)), where expm1(z) = ez − 1 is evaluated accurately for small z. Let K
be the number of fractional input-bit positions inspected. Read the bits of |x| for k = 3, 2, . . . , −K.
Keep a numerator N and denominator D initialized to zero and one. When the bit for δ is one,
update both using their previous values,
                                 (N, D) ←− (N + tk D, D + tk N ).
The addition formula makes N/D the hyperbolic tangent of the sum of selected angles in exact
arithmetic. To copy a signed intermediate z with |z| ≤ 128 when a bit b is one, the circuit uses
ReLU(z−128(1−b))−ReLU(−z−128(1−b)). Each exact update grows the maximum magnitude
of the coordinates by at most 1 + tk . The factors for the four nonnegative exponents give a product
at most 16. The factors for negative exponents give a product at most exp( k<0 2k ) = e. These
                                                                              P
bounds motivate the choice of 128.

Quotient digits and rounding. Start with a remainder R = N . At fractional position j = 1, 2, . . .,
the next quotient digit is one if R ≥ 2−j D. Subtract 2−j D from R whenever this comparison
succeeds. The final circuit keeps the first 53 significant quotient bits beginning with the first one,
and inspects the following bit, called the guard bit. If it is one, the circuit adds one unit at the last
retained position. To see why the mathematical target has no tie at nonzero binary64 inputs, suppose
tanh x were the midpoint between two consecutive representable values, which is a rational number.
Then e2x = (1 + tanh x)/(1 − tanh x) would be rational. The Hermite–Lindemann theorem says
the exponential of a nonzero algebraic number is transcendental, meaning it cannot be a root of a
nonzero polynomial with integer coefficients. The nonzero rational number 2x meets the theorem’s
hypothesis. Finite-precision comparisons can still produce an incorrect bit.
For |x| ≤ 2−27 , a final gate copies x because 0 ≤ |x| − tanh |x| ≤ |x|3 /3 lies below half the
spacing toward zero. For larger magnitudes the circuit restores the sign of x after extracting the
quotient. The 84-fractional-bit construction uses 82 quotient positions. The input and quotient digit
counts are distinct. Each coordinate uses three binary64 words representing a leading part and two
corrections. The circuit combines rounded sums, constant products and their rounding residuals,
recording successive corrections across the words. It stores 525 coefficient words and uses 2,146
rectifiers. Expanding repeated uses and fixed unit edges gives 75,973 affine coefficient occurrences.
A traversal of the graph checks that every product has an input-independent factor.

One update per instruction. Let R be the number of registers, P the number of instructions, G
the number of conditional decrements, and d = R + P the number of stored coordinates. Append
to the register values a one-hot vector of P instruction indicators, with entry pj equal to one for the
active instruction j and zero for the others. Write z ∈ Rd for the resulting state and z ′ for the next
state. Let D be a d × d matrix that directly updates the state, W a G × d matrix testing conditional
instructions, and E a d × G matrix routing the branch corrections. With a componentwise rectifier,
one update is
                                  z ′ = ReLU Dz + E ReLU(W z) .
                                                                      

The register block of D copies each register. Its column for an increment adds one to the named
register and places the active bit at the destination. Its halt column retains the current instruction bit.
For a conditional decrement of register r at instruction j, the corresponding hidden unit computes
ReLU(pj − zr ). This equals one precisely when this instruction is active and the register value is
zero. The corresponding column of D attempts a decrement and selects the positive destination.
A unit hidden bit switches the destination through E. It can also cancel the attempted decrement.
Alternatively the outer rectifier clips the attempted −1 to zero. In both cases every legal integer state
advances exactly one instruction under exact arithmetic. Induction gives the specified states at every
finite time.

W     Choosing both the operations and the weights
We asked whether Astra could implement square, sine or positive self-power when it could choose
the circuit topology, meaning the operations and their connections. A domain-specific language
(DSL) restricted the allowed operations. Each reply was an instruction list written in JavaScript
Object Notation (JSON), a text format for structured data. A wire carries the value computed at
one graph node. An input-dependent wire can vary with the input, while an input-independent wire
carries a fixed constant. The affine/rectifier operator set permits addition, subtraction, multiplication
by an input-independent constant, division by a constant and rectification. A second operator set
also permits products of two input-dependent wires. In both sets, constants can use sine, logarithms
and other elementary functions when the graph is built. For each unseen input, inference executes
only the resulting fixed circuit. Every operation that depends on the input counts once toward the
4,096-operation cap after expansion of loops with fixed bounds. Precomputed constants, the size of
the instruction text and the number of wires are separate costs.
Each prompt supplied the target formula, input interval, arithmetic rules and operation cap. Eighteen
independent requests covered three targets, two operator sets and three replicate labels (9213, 2451
and 8282). The labels distinguish calls with the same instruction, without changing their inputs. The
model returned weights and topology without a given Xavier array, tools, examples or evaluation
