# Paper tables for matched one-shot, iterative and gradient endpoints

From the repository root, run `python focus/iterative_tables/report.py` with Matplotlib installed. The default build requires both `focus/iterative/FROZEN.json` and the independent scorer's `focus/iterative_eval/audit.json`. It reads the scored endpoints and comparators from that scorer. It validates 87 settings × eight methods × three splits, unique settings, finite metrics and matched sample sizes before generating any publication output.

* `representative.tex` gives outer-test exact counts and raw root mean squared errors at the ten prespecified sizes.
* `endpoint_tables.tex` gives the corresponding results for all 29 task–size pairs. The first table covers extrapolation, the second strictly held-out central inputs, and the third the original training examples. Each method's exact count and error are separate medians across the same three starts. The saved full-precision `size_medians.csv` contains all 696 method–size–split entries.
* `figure1.tex` shows four directly labeled medians of scaled outer-test RMSE. `paired_table.tex` gives training, central/early and outer median scaled RMSE for all eight methods, plus the number of fully exact outer sets. `method_endpoints.csv` records these summaries. Scaling divides each coordinate error by the larger of one and the absolute target before calculating RMSE within a setting. We recompute from the saved weights using a stable norm, including a large Fibonacci residual whose naïvely squared loss overflows.
* `paired_settings.csv` lists both endpoint scores and their signed difference for each matched setting. `paired_summary.csv` reduces these data to counts of better, equal and worse results. The files also cover adaptive moment estimation (Adam) followed by full BFGS, and trust-region least squares. Exact-count comparisons favor more matches. Error comparisons favor smaller errors.

For integer sequences, the central comparison uses the held-out indices 17–32 for every method. The feedback loop was given indices 9–16. Outer integer tests use indices 33–64. Outcomes are comparisons of the returned networks at bounded computational budgets and include any incumbent retained by early stopping.

A pre-freeze layout proof is available with `python focus/iterative_tables/report.py --layout-proof /tmp/wsp-layout`. This mode substitutes round-zero values only for testing typesetting, labels each display as unmeasured, can only write to a temporary directory, and does not issue data files. The release path has no such substitution.
