# Common-objective weight-space programming (WSP) runs

These 48 independent prompts cover eight targets, three seeds and two information conditions. They specify exactly the same empirical objective as the numerical solvers. Each response returns one array per eligible graph size (two for running sum, three otherwise). Together with the 12 arithmetic requests in ../arithmetic they form the primary WSP comparison. The old prompt in extension/writer requested low maximum scaled error and is a separate preliminary experiment. Input arrays, seed conventions, training labels, held-out data and initial arrays are shared with its numerical optimizer checkpoints.

To regenerate prompts, run the environment's Python on focus/objective/experiment.py design from the repository root. The existing runner extension/writer/run.py accepts --folder plus the absolute path of this directory and --workers followed by a worker count. New calls require an authenticated model session; the first returned answer is archived. To replay the archived replies without making model calls, run focus/objective/experiment.py score. The status table records absent or invalid arrays. Each score row uses the original target's output units and exact-match denominator, and includes the empirical training loss. Model calls receive no held-out scores.
