# Matched literal weight writing and backpropagation

Ten tasks × three starts × two information conditions = 60 calls. Each produces three complete vectors. The displayed weights and labels are identical across arms; anonymous prompts omit task names but retain informative interfaces. All 180 arrays parsed. Run python extension/writer/compare.py fit to refit the 90 controls, python extension/writer/compare.py score to replay the writers, BP and untrained arrays, and python extension/writer/report.py for medians. Scores include observed, held-out central, left/right, whole-output exactness, one-ULP, tolerance and scaled error. Run design.py then run.py in a fresh copy for new calls. The three architectures within each call are dependent. The formula arm knows the rule; the examples-only arm can still use the model's prior knowledge. See ../optimizer/ for certified loss gaps and stronger methods and ../recurrent/ for conventional tanh/GRU fits.
