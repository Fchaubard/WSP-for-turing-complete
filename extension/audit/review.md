# Independent review against the original question

**Scope.** Reviewed the existing manuscript and archived experiments as a numerical and identifiability study, then checked the new lattice result separately. The strongest scientific claim is the sparse edit law for a specified nonzero scalar recurrence. The proof treats the inaccessible/unobservable strata needed for a generic lower bound and has an explicit matching coordinate construction. I found no missing case. It counts changed scalar coordinates in a *fixed* linear system, whereas the architecture sweeps count all stored or executed coefficients. Those quantities answer different questions.

## Ranked open questions and controls

1. **What a weight-writing model can find from observations.** One literal proposal per scalar/discrete task and six paired recurrence prompts demonstrate existence in those cases. In the existing experiment, the literal writer generally knows the target rule, the parameter layout, the architecture, and sometimes the full numerical envelope. Neither a central-label optimizer nor a whole-vector pass rate estimates this discovery ability. A stronger matched design randomizes a compact, private recurrence family with unknown signed coefficients or unknown sorting wire maps. For each target and initialization, give an independent writer only central observations, a second writer the exact rule, and a third solver the same information as each arm. Keep architecture and permitted tooling fixed, rotate readout coordinates or neuron labels, score each first response without repairs, and hold raw transcripts and precommitted generator seeds. Report target-level success, token/solver budgets and invalid proposals. This distinguishes a familiar template copy from extrapolation under an explicit hypothesis class. It also distinguishes success of a purpose-written compiler from a sampled Astra run.
2. **How small is an exact binary64 network?** The homogeneous recurrence-order minima, real gate minimum for sorting four values, and real worst-case shallow-square result each fix architectures and arithmetic. The robust sort compiler gives an upper bound, and the compensated square succeeds on a large test while failing on adversarial inputs. Neither determines optimal cost over arbitrary binary64 ReLU circuits. This extension supplies a precise finite-test optimum and a global lower bound for one bounded coefficient class, including actual internal rounding. A 160-hinge circuit can score 321/321 on a grid and 0/320 a half-grid step away. Even 1,280 hinges are necessary to solve all binary64 squares under the stated shallow constraints. The global sufficiency threshold, unrestricted coefficient case, deep square optimum and binary64 gate minimum for sorting remain open. Native tanh, tied comparators and built-in input routing must be priced as specified primitives alongside the numerical slot count.
3. **Which smooth targets attain the requested criterion?** The existing native tanh match tests identity input/readout around the very same library tanh. Those are legitimate identity weights, with transcendental evaluation supplied by that primitive. Positive self-power and folded sine approximate their targets at the reported sizes. An architecture with a given activation, an exact correctly rounded primitive and a generic ReLU approximation should be reported separately. A strict IEEE claim for sin/tanh/pow requires a correctly-rounded high-precision oracle and an explicit signed-zero policy; reproducing a particular NumPy implementation is a different operational benchmark. There is no conventional real self-power on the negative noninteger binary64 part of the shell.
4. **Which conclusions follow for backpropagation?** Finite Adam/BFGS sweeps and a few starts show what those runs learned. They coexist with exact gradient-based counterexamples, including an adaptive running-sum control already in the paper. A rule-aware writer and sample-only learner observe different information. Compare end-to-end BP with fixed feature/readout regression, architecture-constrained optimization, and equation/system identification under equal observations and hypothesis classes. Record a BP negative result as a measured rate and an architectural impossibility separately. The lattice extension gives a positive label-only control: a known quadratic class, three central labels, and a known deployment lattice suffice for gradient fitting plus compilation to the identical 482-slot network; a degree-unconstrained interpolation of all 97 central labels misses every shell site.
5. **Numerical stability and uncertainty.** Exact rational writes at the attained edit budget can require long coefficients. Rounding the same rational pole-placement solutions left 15/75 exact on all 32 direct impulses. Whole-stream exactness depends on emitted products, addition order, BLAS, and the use of fused operations. On an independent NumPy runtime I regenerated all literal prompts identically and recovered the same qualitative and exact-count outcomes, with last-bit changes to several small residuals. For a *pre-fixed* circuit with 131,072 independent, all-success outer queries, the one-sided 95% binomial upper bound on failure probability is about 2.29×10⁻⁵ (1−0.05^(1/131072)). This is conditional on that input law; the midpoint and underflow panels probe different populations. Report optimizer and writer uncertainty at the seed/target level.
6. **Computability and publication.** A fixed finite-dimensional homogeneous linear RNN realizes finite-order impulse sequences; a fixed finite-precision deterministic RNN has finitely many internal states. Classical Turing simulation uses a different computational model. Neither a handful of computable functions nor perfect finite-grid accuracy resolves learning of arbitrary Turing-computable functions. The existing draft's narrower scope is defensible. Before a public preprint, author approval/publication and independent reproduction remain separate from the production of the local paper package.

## Checks performed

- Reviewed the generic edit theorem, including the defective/unobservable case m<r. The leading r-by-r Hankel block is invertible by recurrence minimality. Deleting rows and columns gives rank at least H−r in the only subtle truncated case. A quotient characteristic-polynomial submersion, m linear constraints on the input vector and a Grassmannian dimension count finish the lower bound.
- Checked the numerical contract of the existing bounded comparator, including the minimum subnormal gap and signed-zero convention. The original edge counts include structural edges and designated biases. Its proof guarantees equality of numeric values with signed zeros identified. It concerns a prescribed bounded range and explicit operation order.
- Verified all archived literal prompt strings from their generators and rescored all 21 replies. The record contains the requested model alias and summarized CLI activity. A resolved provider-side model snapshot or complete tool actions are unavailable from those summaries.
- Added a standard-library 322-configuration, three-split lattice sweep and four resolution checks. Its correctness certificate controls every binary64 operation and the number of hits a real affine piece can support once the smallest lattice separation is known. See the accompanying derivation and JSON. No submitted results establish a universal binary64 lower bound for networks with arbitrary internal coefficient magnitudes.
