# Direct circuit synthesis

Three targets × two operator sets × three independent replicates = 18 distinct requests. We bounded the expanded graph size and parsed a JSON language which cannot execute arbitrary Python. Sixteen returned on the original 300-second budget. Two affine/self-power requests timed out and were recollected before grading, one reply per case; the returned programs were invalid JSON and over budget respectively. The matrix retains both failures. All returned CLI metadata show only an agent message. This protocol asks Astra to choose its graph and coefficients; no supplied initializer constrains the free topology.

To replay, run python experiment.py score (NumPy and gmpy2), then python paper_table.py. challenge.py grades fresh random samples, difficult square midpoints, exponent ranges and a pinned public worst-case sine corpus. It accepts --core /path/to/sin.wc or downloads the independently hashed source. literal_square_certificate.py directly checks one original model against integer-rational square reference values near ties, exponent boundaries and normalization thresholds. The paper gives the separate proof of correctness for every binary64 input on both shells. Use python infer.py -9.5 3 4 10 to run that released literal ReLU graph without MPFR or source labels. For an archived correction, use --stage repair --id followed by a replicate-9213 ID. See repair/ for the six central-feedback pairs and full accounting. MPFR normal outputs use round-to-nearest at 53 bits; square adversarial reference uses the native correctly rounded binary64 product or one-round exact rationals as specified per test.
