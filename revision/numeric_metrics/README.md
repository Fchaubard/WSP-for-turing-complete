# Numerical and circuit experiment errors

Each CSV row is one method, architecture, input split and (where applicable) trial. The exact column counts scalar predictions that compare equal to their reference, with the two numerical zeros identified. The n column gives its denominator. The additional exact_bits column for square counts identical bit patterns including the sign of zero. raw_rmse is the square root of the arithmetic mean of squared errors in the target's original units. Positive values can be below the smallest positive binary64 number. To avoid overflow and losing such values to final underflow, the scorer divides errors by their maximum absolute value, forms their mean square in binary64 and performs the final rescaling in decimal arithmetic. A zero value with a full exact count means every numerical output agreed. No estimate combines different targets or independent runs.

- scalar.csv reproduces all scalar and product-graph size sweeps, including the sine Adam (all_slot_adam) and nonlinear least-squares (central_gauss_newton) controls. Other coefficient families were constructed by WSP. order and stage retain the parameter conventions of extension/scalar. The outer split combines both signed sides for sine and uses only positive inputs for self-power.
- tanh.csv compares the native library with the different WSP graph precisions and sizes, using the correctly rounded mathematical hyperbolic tangent for all. smooth_adam.csv compares the deployed self-power and tanh graphs with each training run's initial and final stored coefficients. WSP has no random trial, recorded as seed zero.
- synthesis.csv reports every frozen first response. unavailable_invalid marks a response with no executable circuit. nonfinite denotes a scored panel on which at least one absolute prediction error was nonfinite; every input remains in its reported denominator. repair.csv pairs each selected frozen response with its central-feedback revision on identical samples. These are topology-generating WSP trials. Their operators and topologies vary by response.
- machine.csv compares predicted and interpreter-generated register states or terminal scalar outputs. For one_step_state each observation is a scalar state coordinate from a single transition. For autonomous_state each observation is a scalar coordinate from one step after initialization in one independently started trace. final_scalar weights each initial condition once. The six relabeled trials (WSP_Astra) are separate; all full-state predictions matched their reference, so their component RMSE is exactly zero. The structured solver learns a discrete instruction table. Each bp seed denotes a continuous gradient fit.
- square.csv distinguishes the frozen first WSP reply from the engineered all-domain WSP circuit on identical inputs, with exact-rational square rounded once to binary64 as their shared reference.

From the repository root, run each script with the project's numerical Python environment. They read archived outputs/coefficients and use deterministic input generators. smooth.py and tanh_metrics.py accept an optional --core FILE for their upstream CORE-MATH sine or hyperbolic tangent corpus respectively. responses.py accepts the same sine corpus option. Without it they retrieve the pinned source. Scalar, tanh, synthesis, repair and smooth gradient scripts check that all replayed counts agree with the pre-existing result files where the matching split is present.

    python revision/numeric_metrics/smooth.py
    python revision/numeric_metrics/tanh_metrics.py
    python revision/numeric_metrics/responses.py
    python revision/numeric_metrics/smooth_adam.py
    python revision/numeric_metrics/machine.py
    python revision/numeric_metrics/square.py
